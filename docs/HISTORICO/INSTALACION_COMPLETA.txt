🚀 COMO INSTALAR (3 PASOS SIMPLES):

PASO 1: Asegurate de estar en el directorio del proyecto
────────────────────────────────────────────────────────
$ cd ~/stockhogar
$ ls install.sh
# Debería mostrar: install.sh


PASO 2: Ejecutar el instalador
─────────────────────────────
$ bash install.sh

El script hará AUTOMATICAMENTE:
  ✓ Verificar que usas Raspbian
  ✓ Actualizar el sistema
  ✓ Instalar Docker
  ✓ Instalar Docker Compose
  ✓ Crear directorios necesarios
  ✓ Crear archivo .env
  ✓ Construir imagen Docker (10-20 minutos)
  ✓ Iniciar contenedores
  ✓ Verificar que todo funciona


PASO 3: Acceder a la aplicacion
──────────────────────────────
Abre en tu navegador:
  http://localhost:5000

O desde otra maquina en la red:
  http://<IP-RASPBERRY>:5000

Para encontrar tu IP:
  $ hostname -I

🔧 COMANDOS PRINCIPALES:

Ver logs en tiempo real:
  $ docker-compose logs -f stockhogar

Detener la aplicacion:
  $ docker-compose down

Reiniciar:
  $ docker-compose restart

Recrear contenedores (si hay problema):
  $ docker-compose up -d --force-recreate

Abrir terminal en el contenedor:
  $ docker-compose exec stockhogar bash

Ejecutar comando Python:
  $ docker-compose exec stockhogar python3 -c "import flask; print('OK')"

Mantenimiento:
  $ bash maintenance.sh

🆘 SI ALGO SALE MAL:

1. Ver logs:
   $ docker-compose logs stockhogar

2. Verificar estado:
   $ bash verify.sh

3. Reiniciar:
   $ docker-compose restart

4. Si sigue fallando, reconstruir:
   $ docker-compose down
   $ docker-compose up -d --force-recreate
   $ bash verify.sh
