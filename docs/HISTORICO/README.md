# ⚠️ Archivo histórico

Los documentos de esta carpeta son snapshots de fases de desarrollo pasadas
(refactorizaciones, implementaciones puntuales, checklists de pruebas, notas
de una sesión de trabajo concreta, etc.). **No se mantienen actualizados** y
pueden describir un estado del código que ya cambió o fue sustituido.

Para la documentación vigente del proyecto, usa los documentos en `docs/`
(fuera de esta carpeta) y el `README.md` de la raíz del repo.

Si necesitas contexto histórico de por qué se tomó una decisión concreta,
estos archivos pueden servir de referencia, pero verifica siempre contra el
código actual antes de asumir que algo aquí descrito sigue siendo cierto.
